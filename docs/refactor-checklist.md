# 人工回归清单（Maintainability Refactor）

每次阶段（Phase）完成后，由维护者在本机 GNOME 会话中手动验证以下清单。
构建方式：`scripts/local_install.sh`（或 meson 构建）后重启 GNOME Shell（Alt+F2 → r）。

## 基础功能

- [ ] 桌面图标正常显示（文件、文件夹、特殊图标 Home/Trash、挂载卷）
- [ ] 开机/启用扩展后 DING 子进程正常启动（`pgrep -f ding.js` 存在一个进程）
- [ ] 子进程被杀后 1 秒内自动重启
- [ ] 扩展禁用后子进程退出、无残留（`pgrep -f ding.js` 为空）

## 拖放

- [ ] 桌面内拖动图标 → 图标位置移动并持久化（重启后位置不变）
- [ ] 从 Nautilus 拖文件到桌面 → 复制/移动（按 Ctrl 切换语义）
- [ ] 从桌面拖文件到 Nautilus 窗口
- [ ] 拖文件悬停到桌面图标上 → 目标高亮正确
- [ ] 多选拖拽 → 堆叠 ghost + 数量角标
- [ ] 从编辑器拖文本到桌面 → 生成 `.txt`（中文文件名、含数字文件名正常，如 "2026 report.txt"）
- [ ] 从浏览器拖 URL 到桌面 → 生成 .txt 或 .desktop 行为与之前一致
- [ ] 文件夹拖到自己 → 无 Nautilus "cannot move folder into itself" 错误

## 右键菜单

- [ ] 桌面空白处右键：新建文件夹/文档、粘贴、排序、堆叠、显示设置
- [ ] 图标右键：打开、打开方式、重命名、复制/剪切/删除/移到回收站
- [ ] 菜单点击外部自动关闭；子菜单往返 hover 后仍能关闭
- [ ] 新建文件夹出现在鼠标点击位置
- [ ] 重命名（F2 与菜单）弹窗正常，重复名提示

## 增量更新与排序

- [ ] 在 Nautilus/终端创建文件 → 桌面图标即时出现（不重建其他图标）
- [ ] 删除文件 → 图标即时消失
- [ ] 重命名文件（含连续快速操作）→ 图标位置保持、标签更新
- [ ] 批量创建 10+ 文件 → 全部出现且无闪烁/卡顿
- [ ] 按名称/类型/大小/修改时间排序正常（注意：数字自然排序为已知未修复项）
- [ ] 堆叠开启/关闭、取消堆叠恢复原位置
- [ ] 按位置排序（四角起点）正常

## 多显示器与几何

- [ ] 插拔显示器 → 图标重新分布、无错屏
- [ ] GNOME 设置中切换主显示器 → 新图标出现在正确屏幕
- [ ] 改变缩放比例 → 图标位置适配
- [ ] 顶部面板高度变化（如扩展加载）→ 可用区域更新

## 概览动画

- [ ] 进入 Overview → 桌面图标淡出；退出 → 淡入（与过渡帧同步）
- [ ] 多显示器下动画正常
- [ ] Overview 切换后图标位置无漂移

## 键盘与剪贴板

- [ ] 方向键导航、Ctrl+A 全选、Ctrl+Space 切换选中
- [ ] F2 重命名、Enter 打开、F5 刷新、字母搜索
- [ ] 桌面空白处粘贴（Wayland 下可用性已修复）——文件从剪贴板粘贴到桌面
- [ ] Ctrl+Z 撤销（GTK Action 路径）

## 缩略图与主题

- [ ] 图片文件缩略图正常显示、尺寸不超过图标大小
- [ ] 修改图片后缩略图刷新
- [ ] 切换 GNOME accent color → 选中色即时更新（无需重启）
- [ ] 暗色模式切换 → 图标标签可读

## 稳定性

- [ ] 长会话（>30 分钟）无内存异常增长（`/proc/<pid>/status` VmRSS 观察）
- [ ] 日志无 `TypeError`/`ReferenceError`/`Unhandled promise rejection`（`journalctl -f` 过滤 gjs）
- [ ] `scripts/check.sh` 通过（ESLint + 语法 + 单测）
